\# Contributing to DevPocket



First off, thank you for considering contributing to DevPocket!



\## How to Add a New Tool



1\. Create a new file in `js/tools/your-tool.js`.

2\. Add the tool's metadata to `js/registry.js`.

3\. Add the script tag to `index.html`.

4\. Test it locally and open a Pull Request!



\## Questions?

Open an issue. We're friendly!
