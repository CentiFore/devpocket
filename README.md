# 💻 DevPocket

A modern, fast, and free collection of developer tools that run entirely in your browser.

🌐 **[Live Demo](https://centifore.github.io/devpocket/)** 

---

## ✨ Features

- **10 powerful tools** — JSON Formatter, Base64, URL Encoder, Color Picker, UUID Generator, Lorem Ipsum, Markdown Previewer, Snippet Manager, Text Counter, Timestamp Converter.
- **100% client-side** — No backend. Your data never leaves your browser.
- **Beautiful UI** — Modern dark theme with neon accents.
- **Fully responsive** — Works seamlessly on desktop, tablet and mobile.
